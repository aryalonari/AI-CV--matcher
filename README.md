# AI-Powered CV Matcher

## Overview
This system analyzes multiple CVs against a given Job Description and
generates a job-fit score (0–100) with key insights using an LLM.

## Features
- Bulk CV upload (PDF / DOCX / TXT)
- Job description analysis
- AI-based scoring & insights
- Clean UI dashboard

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- AI: OpenAI API
- File Parsing: pdf-parse, mammoth

## How to Run Locally
### Backend
```bash
cd backend
npm install
